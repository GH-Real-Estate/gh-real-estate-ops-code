# Initial release build scripts

These scripts reproduce or document the July 12, 2026 source-pack build. They retain fixed retrieval dates, Kansas legislative-session paths, and build-environment assumptions for auditability.

They are not the scheduled currentness monitor. Before using them for a later release, refactor and review all fixed dates, session identifiers, official URLs, filesystem paths, dependency versions, fonts, and known source-access exceptions. Never interpret a successful rebuild as legal approval of changed text.
