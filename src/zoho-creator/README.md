# Zoho Creator

Use this area for sanitized Zoho Creator app exports and import notes.

## Contents

```text
docs/
  import-notes.md
```

Sanitized `.ds` exports may be added later only if they contain structure/configuration and no tenant data, portal users, files, signatures, payment records, or maintenance photos.

## Rules

- Do not commit live Creator exports unless they are fully sanitized.
- Do not store real portal users or tenant records here.
- Document import errors and smoke tests in the relevant notes.
